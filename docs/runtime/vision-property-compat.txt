Vision property compatibility audit

Failure sequence
- Startup passed the projectile and ballistic registry checks.
- Gates of Hell 1.064.0 first rejected `firing_silent_pb` while expanding the modern optic rules.
- Restoring the Code-X term registry advanced startup to `cannon_01a` and then to `vision_radar_shipSAM`.
- Restoring the omitted radar-helper block advanced startup to `("vision_optic" args 70)`.
- That failure proved the compatibility-edited file was structurally mixed: `vision_optic` had been converted into a named `{...}` object while consumers still invoked it as a reusable `(define ...)` macro.
- Replacing the three-file modern vision contract advanced startup into SC Platform's effective `vision_fields.inc`.
- SC's `sc_fauna_spot_props` exposed a repeated seven-line target pattern: size one begins at line 4, size two at line 25, size three at line 46, and size four at line 53 after the size-three base entry.
- The earlier assumption that size three was terminal was wrong. Runtime evidence does not reveal the packed definition's final size without extracting the SC gamelogic package.

Compatibility decision
- Mod #5 owns the exact Code-X `vision_generic.inc` and `new_vision.inc`.
- Mod #5 owns Code-X `settings.set` plus a bounded SC Platform actor-term namespace guard.
- The guard registers sizes 1 through 32, each with the base, `_s`, and `_ss` variants, for 96 unique inert actor-term declarations.
- Registering an unused actor-term does not alter SC spotting behavior; it only allows later-loaded SC rules to resolve the actor category when present.
- No SC detection distance, firing visibility, line-of-sight persistence, or still-unit timing is changed.
- The temporary generic-firing collapse and manually reconstructed vision objects remain removed.
- Reusable contracts including `vision_optic`, `vision_optic_driver`, modern optic generations, radar helpers, and acoustic helpers remain `(define ...)` macros.
- No weapon damage, faction registration, Dynamic Conquest economy, or campaign matchup values are changed.

Validation
- Tests verify all matched modern vision files are locally owned.
- Tests verify `vision_optic` and other reusable contracts remain defines rather than named objects.
- Tests verify every `vision_*` macro call in the owned family resolves to a definition in the owned family.
- Tests generate and verify all 96 SC trooper actor registrations and require each declaration to appear exactly once.
